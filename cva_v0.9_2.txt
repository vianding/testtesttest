Original Collateral Default is a composite contractual credit trigger. It includes Failure to Pay, acceleration-type Default, Repudiation/Moratorium, Restructuring, Governmental Intervention, Conversion, Bankruptcy and Mandatory Tender Offer. These events are distinct contractual routes to the same Condition 8(c) consequence; the first qualifying event terminates the performing state. The definitions substantially overlap with credit-derivative credit-event concepts, although the SPIRE trigger set is not identical to any single CDS Credit Event definition. [MODEL CHOICE] For valuation, the sovereign issuer credit curve is used as the market calibration instrument for the aggregate probability of reaching an Original Collateral Default state. Any difference between the contractual SPIRE trigger set and the market credit-event definition underlying that curve constitutes event-definition basis risk.
