# Project Roadmap and Enterprise Evolution

The project has now evolved beyond simply implementing the original PDF proposal.

Going forward, please distinguish between **model evolution** and **production maturity**.

The roadmap should therefore be organized into three versions rather than four implementation phases.

---

# V1 — Reference Implementation

**Objective**

Produce a clean, well-architected implementation that faithfully reproduces the economics of the original PDF proposal and the accompanying email / Excel prototype.

V1 consists of:

### Phase 1

Credit / Wrong-Way Risk model

* CIR hazard process
* CCF model
* EAD model
* Survival-adjusted Expected Loss
* Breakeven spread solver
* Diagnostics

### Phase 2

Liquidity option model

* OU spread dynamics
* Longstaff-Schwartz pricing
* LP option cost
* CostModel integration
* Diagnostics
* Validation against the Excel prototype

Deliverable:

A reusable quantitative library capable of producing

* Expected Loss
* Liquidity Cost
* Capital Cost
* Breakeven Facility Spread

along with supporting diagnostics.

The objective of V1 is **faithful reproduction of the proposed economics**, not production deployment.

---

# V2 — Research Model

After V1 is complete, the next objective is improving the mathematical model itself.

Primary focus:

## Joint dynamics

Instead of treating the major components independently, introduce realistic dependence between

* credit quality,
* macro factors,
* LP spreads,
* utilisation / drawdown behaviour.

Examples include:

* correlated Brownian motions,
* shared macro factors,
* correlated state processes,
* stochastic macro models,
* richer drawdown models.

Additional possible research improvements include

* hazard curve calibration,
* empirical CCF calibration,
* richer LP dynamics,
* state-dependent LGD,
* portfolio extensions,
* variance reduction,
* convergence analysis.

The emphasis of V2 is **better modelling**, not production infrastructure.

---
